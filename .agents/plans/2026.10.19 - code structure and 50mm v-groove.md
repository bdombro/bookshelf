## 1. ✅ 50mm V-groove backs

Change the backs from 100mm to 50mm groove centres.

- Find a 9mm MR MDF sheet with 50mm centres, or a quote for Strahan custom grooving
  (spec Decisions says they offer custom centres). Update `back_sheet` in config.
- Set `groove_spacing = 5`. 113.7cm units stay symmetric (bay centres 55cm apart, a
  multiple of 2.5) and stay the widest that fits: the next symmetric width is 118.7cm.
- Check the back's cut placement and groove counts in `instructions.md`.
- Spec: 3.5 and 4.1 say 50mm; log 100mm in Decisions.
- **Halt:** if no supplier sells or grooves it, or the sheet price rises, report options
  and cost before changing anything.

## 3. ✅ Model as functions over settings

`model.py` runs everything at import time from `config`, so other settings can only be
tried by copying the source (as done to test the new checks).

- A pipeline of functions: settings → derived sizes → parts → checks → hardware →
  packing → outputs, with one entry point that `just build` and `just view` call.
- Settings passed in, not imported deep down, so tests can override single values.
- **Done when:** `build/` is byte-identical to before.

## 4. ✅ Split into folders

A suggested shape; adjust while doing it:

- `src/bookshelf/`: `settings/` (design dimensions; catalog of sheets and products with
  prices and links), `model/` (sizes, unit, layout, checks, hardware counts), `packing/`
  (packer, self-check), `outputs/` (STEP/STL/front view, materials.md, sheet diagrams,
  instructions.md), `rows.py` (`Part`, `Hardware`, `Placement`), `build.py` (entry).
- Keep it runnable with `uv run`; add a package entry only if imports need it.
- Update README "Changing it" to point at the settings folder.
- **Done when:** `just check` passes and `build/` is byte-identical.

## 6. ✅ Instruction prose in a Markdown template

Steps are long text inside Python strings, so rewording one means editing code. A Jinja2
template keeps prose in Markdown with loops for per-sheet and per-bay tables.

- Gain is moderate: much of the text is computed. Decide after 4, when
  `instructions.py`'s split shows how much prose is static.

## 7. ✅ Dry dowels and face-down assembly

Replace pocket screws and plugs on the visible horizontals with dry (unglued) dowels, and
assemble face-down so nothing turns over before the back is screwed on.

- **Dowels, no glue:** every horizontal between a side and the divider is located by
  dowels (shelves, bottoms, cabinet tops, cabinet shelves). Per end: same count rule as
  pockets. Positions from the front edge, offset between the bays so holes from both
  faces of the divider never meet; a model check enforces the clearance.
- **Screws stay where they tie the carcass and are hidden:** the top (pockets, long
  screws into the divider), narrow bottoms and kickboards (pockets on hidden faces), and
  corner braces under the cabinet's bottom and cabinet top. Plugs go.
- **No glue anywhere**, so no taping off glue areas, and the units come apart.
- **Tools and hardware:** dowels, a self-centring dowel jig, dowel centre points, with
  products and estimated prices in the catalog.
- **Assembly, face-down on the front edges:** one side propped on edge → first bay's
  horizontals (kickboards on 5cm spacers) → divider → second bay → other side → top →
  square and screw the back → stand up → corner braces through the cabinet opening.
- Spec 3, 4.2, 5, 6.5 and 7; Decisions: pocket screws and plugs on open shelves, glued
  dowels, assembling on its side, assembling on the back.
